Comment récupérer le bon lien Maps
  1. Dans Google Maps, ouvre la fiche du commerce, puis Partager → Copier le lien.
  2. Si tu obtiens un lien court (maps.app.goo.gl/…), ouvre-le sur un ordinateur, attends que la carte s'affiche, puis copie le long lien de la barre d'adresse.
  3. Sur téléphone : dans Safari ou Chrome (pas l'appli Maps), va sur google.com/maps, cherche le magasin, touche sa fiche, puis copie l'adresse de la page dans la barre du haut.
  4. Colle ce long lien ci-dessus. Il doit contenir un code du type 0x47e6…:0x1078….
Programmer la carte avec NFC Tools
  1. Envoie-toi le lien par message et appuie dessus : vérifie que la fenêtre d'avis s'ouvre sur le bon commerce.
  2. Dans NFC Tools : Écrire → Ajouter un enregistrement → URL / URI, colle le lien.
  3. Appuie sur Écrire et approche la carte du téléphone.
  4. Teste la carte, puis verrouille-la (Autres → Verrouiller le tag). Le verrouillage est définitif.
